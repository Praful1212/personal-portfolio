Autonomous AI-Powered Ops Monitoring & RCA Platform

Azkaban / Spark / YARN · ChromaDB Vector Store · FastAPI · Slack Webhooks
GenAI in Production Zero-Cost Repeat Triaging FastAPI ChromaDB Langflow

Pipeline failures in enterprise big-data clusters often waste crucial engineering hours in repetitive log parsing. I designed and shipped an autonomous 8-node automated diagnosis pipeline that monitors Spark, YARN, and Azkaban clusters every 60 seconds.

  • Instant Automated Triaging: Detects pipeline crashes, extracts relevant error stack traces from driver/executor logs, and bypasses manual log scouring.
  • Zero LLM Cost for Repeat Failures: Employs Retrieval-Augmented Generation (RAG) on ChromaDB to match stack traces against known past Root Cause Analyses (RCAs), retrieving verified fixes with zero external LLM API cost.
  • Drastic MTTR Reduction: Dispatches pre-formatted Slack alerts to on-call engineers with exact root causes and remediation action items, slashing Mean Time To Resolution from tens of minutes to seconds.

Real-Time Customer Location Enrichment Stream

Apache Kafka · PySpark Streaming · GeoHash Derivation · CleverTap Adaptor
Sub-Second Streaming Replaced 30-Min SFTP Batch Apache Kafka GeoHash CleverTap

Customer geographical location data at Paytm was originally bound to a brittle 30-minute batch SFTP process, causing significant lag in personalized merchant offers and real-time consumer engagement.

  • Continuous Event Stream: Engineered a resilient Kafka streaming pipeline replacing the legacy batch mechanism.
  • Dynamic GeoHash Enrichment: Ingests high-frequency location signals, applies GeoHash spatial index derivation, and enriches user coordinates with state and city metadata on the fly.
  • Live Downstream Synchronization: Sinks enriched events into targeted Kafka topics feeding an external adaptor that continuously synchronizes live city/state attributes to customer profiles in CleverTap.
